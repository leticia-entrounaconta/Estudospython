# Estudos de Python — Estágio CCO

Este repositório reúne exercícios e projetos desenvolvidos durante o estágio na área de **CCO**, com foco no aprendizado de Python, lógica de programação e boas práticas de desenvolvimento.

## Objetivos

* registrar as atividades realizadas no estágio;
* praticar fundamentos de Python;
* desenvolver lógica de programação;
* aprender Git e GitHub;
* criar soluções aplicáveis ao ambiente profissional.

## Conteúdos estudados

* variáveis e tipos de dados;
* entrada e saída de informações;
* estruturas condicionais;
* laços de repetição;
* funções;
* tratamento de erros;
* manipulação de strings;
* validação de dados;
* boas práticas da PEP 8.

## Projetos desenvolvidos

Entre as atividades presentes no repositório estão:

* calculadora;
* conversor de moedas;
* normalizador de nomes;
* validador de CPF;
* exercícios de lógica de programação.

## Como executar

Verifique se o Python está instalado:

```bash
python --version
```

Execute uma atividade com:

```bash
python nome_do_arquivo.py
```

## Atualizar o repositório

```bash
git status
git add .
git commit -m "Atualiza atividades de Python"
git push
```
