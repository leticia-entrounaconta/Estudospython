# Gerenciamento de Clientes

Este projeto realiza operações básicas em uma lista de clientes.

## Funcionalidades

O programa:

* Exibe todos os clientes cadastrados;
* Mostra a quantidade total de clientes;
* Adiciona um novo cliente;
* Atualiza o status de um cliente pelo CPF;
* Remove um cliente pelo CPF;
* Exibe a lista atualizada.

## Estrutura dos dados

Cada cliente é representado por um dicionário contendo:

* Nome;
* CPF;
* Idade;
* Status ativo ou inativo.

## Conceitos utilizados

* Listas;
* Dicionários;
* Laço `for`;
* Condicionais;
* `append()`;
* `remove()`;
* `len()`;
* `break`;
* `None`;
* F-strings.

## Exemplo de saída final

```text
Lista atualizada:
João Silva - Ativo
Maria Souza - Ativo
Ana Pereira - Ativo
```

## Como executar

```bash
python nome_do_arquivo.py
```
